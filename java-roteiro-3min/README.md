# FreshFlow em 3 minutos

Projeto Java simples para apresentar, no terminal, o roteiro enxuto da apresentação Raiz Viva FreshFlow.

## Como rodar

Com Java 17 ou superior:

```bash
javac src/main/java/br/com/raizviva/App.java
java -cp src/main/java br.com.raizviva.App
```

Com Maven:

```bash
mvn compile exec:java
```

## Estrutura da fala

1. Problema
2. TOGAF ADM
3. FreshFlow
4. ArchiMate
5. Governança
6. Fechamento

Tempo total estimado: 3 minutos.
